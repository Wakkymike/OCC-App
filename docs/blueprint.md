# **App Name**: BNGN Bus Tracker

## Core Features:

- Live Bus Tracking: Display live bus locations on a map using the BNGN bus open data service.
- Vehicle Information Display: Show the fleet number of each vehicle, the service it is operating, and its destination in real time.
- Route Visualization: Highlight the route of the bus on the map for easy understanding.

## Style Guidelines:

- Primary color: Blue (#3498db) to evoke a sense of reliability and clarity, relating to transport services.
- Background color: Light gray (#f0f0f0), providing a neutral backdrop that ensures high contrast and readability for map elements and bus routes.
- Accent color: Orange (#e67e22), used for highlighting selected bus routes and interactive elements to draw user attention.
- Font: 'Inter', a sans-serif font for clear readability on digital displays, suitable for both vehicle information and UI labels.
- Use simple, recognizable icons for bus stops and points of interest, ensuring they are distinct and easy to understand on the map.
- Maintain a clean and intuitive map interface, focusing on minimizing visual clutter to present essential information clearly and efficiently.
- Incorporate smooth transitions and subtle animations for bus movements on the map, offering a seamless and engaging user experience.
